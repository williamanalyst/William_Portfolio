# Piggle lithophane — Bambu Studio guide

`piggle_lithophane.stl` is a solid portrait lithophane made from the supplied photo.

- Finished size: approximately **100 × 178 × 3.2 mm**.
- In Bambu Studio, import the STL and leave it flat, as supplied.
- Use a light-coloured, opaque PLA (white is ideal), 0.16–0.20 mm layer height, 3 walls, and 100% infill for the clearest result.
- No supports are needed.
- The portrait looks best held in front of a lamp, window, or LED backlight; the image detail is intentionally subtle under normal front lighting.

This model is a 2.5D photographic relief, not a full 360-degree figurine. A full figurine requires multiple reference angles or a dedicated 3D scan.
