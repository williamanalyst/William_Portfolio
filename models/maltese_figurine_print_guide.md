# Resting Maltese figurine — Bambu Studio setup

Open `maltese_resting_figurine.stl` directly in Bambu Studio. It is a single, sealed, background-free model sized at about **184 × 111 × 106 mm**; scale it down if preferred.

For a light, nearly hollow print in white PLA:

- Filament: white PLA
- Layer height: 0.16–0.20 mm
- Wall loops: 3 (about 1.2 mm shell with a 0.4 mm nozzle)
- Top and bottom shell layers: 4
- Sparse infill: 0–5%; use Gyroid if using 5%
- Supports: **off** initially; the model has broad, low contact areas. If Bambu Studio flags a small overhang under the muzzle, use **tree supports, build-plate only**.

The STL itself is solid by design. The very light internal structure is made by the slicer settings above; this is more reliable than modelling a thin hollow shell.
