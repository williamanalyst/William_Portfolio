# Detailed Standing Maltese STL

File: `maltese_standing_detailed.stl`

This is a single-piece, background-free standing Maltese figurine inferred from the supplied front standing photos plus the side body/fur reference. It keeps the dog only: upright tail, fluffy head, drooping ears, short legs, broader paws, beard/moustache fur, recessed eyes, recessed nose detail, mouth line, toe grooves, and printable surface fur ridges.

## Bambu Studio setup

- Material: white PLA or matte white PLA
- Layer height: 0.16 mm for best detail, 0.20 mm for faster printing
- Wall loops: 3
- Top shell layers: 4
- Bottom shell layers: 4
- Sparse infill: 0% to 5%
- Infill pattern: Gyroid if using infill
- Supports: start with Tree supports, build plate only, because the muzzle, belly, and raised tail may need help
- Seam: back or nearest rear side
- Orientation: paws on the build plate

## Hollow/lightweight note

For FDM printing, keep the STL as a closed solid and make the inside almost empty in Bambu Studio using low infill. This is usually stronger and easier than creating a fragile thin hollow STL manually.

## Optional finishing

The eyes, nose, nostrils, and mouth are recessed so they remain visible in a single white print. Paint the recesses black after printing if you want the model to look closer to the photos.
